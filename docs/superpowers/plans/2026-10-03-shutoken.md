# 首都圏への拡大 実装計画

> 開発時の計画の記録です。現在の実装と手順は README.md と docs/method.md を参照してください。チェックボックスは当時の計画です。
> 設計書: `docs/superpowers/specs/2026-10-03-shutoken-design.md`。手順ごとにテストを先に書き、ブランチ `shutoken` で進める。

## 手順 1: 複数地域への対応 (データは東京だけ)

- [ ] **設定の名前**: `configs/territory.toml` → `configs/territory-tokyo.toml` (`git mv`)。ABR のキーは地域の都県コードから決める (`abr-town-<code>`、`abr-town-pos-<code>`)。`configs/sources.toml` に 11・12・14 の ABR を足す (取得はその県に進むとき)。
- [ ] **駅の共通 ID** (`groups.py`): まとめた駅に `key` = 属する N02 グループコードを並べた文字列 (`"003700|003701"`)。テスト: 同じ駅の組は同じ `key`。
- [ ] **書き出し** (`pipeline.py`): `stations.json` に `key`、`territories.geojson` と `iso/*.json` の属性に `k` (= key)、`adjacency.json` (地域の中で接する駅番号の組)、`meta.json` に `bbox` (範囲の外接矩形、経緯度)。
- [ ] **combine** (`territory/combine.py` と `eki-walk combine --region ...`): 全地域の接する組 (地域の中の組 + 県境で 30m 以内に近づく別地域の面の組) を `key` のグラフにまとめて塗り分け (DSatur、6 色まで)、各地域の `territories.geojson` と `stations.json` の色を書き換え、`data/regions.json` (名前・表示名・bbox・置き場・最初の表示) を書く。テスト: 2 地域の小さな例で、同じ key は同じ色、接する別の key は別の色、`regions.json` の中身。
- [ ] **CLI**: `eki-walk fetch <key>...` (ekiwalk の `download` で取得し、`data/raw/manifest.json` に記録)、`eki-walk combine --region tokyo [--region saitama ...]`。
- [ ] **画面** (`web/app.js`): `regions.json` を読み、見えている範囲と重なる地域だけを読み込む。地点 → その地域の範囲・格子。駅の選択・強調は `key` で全地域から集める (広さは合計、いちばん遠い所は最大、15 分以内の割合は広さで重み付け)。検索は全地域の `places.json`。`?region=` をやめ、試運転用に `?manifest=` で別の一覧を読めるようにする。
- [ ] **確認**: 東京の `stations.json`・縄張りの面積・答え (高円寺南・新高円寺・赤羽北・大泉学園の地点) が変わらないこと。画面 (パソコン幅・スマホ幅)、コンソールのエラーなし。
- [ ] **公開の確認を取る** (main へのマージ・push・gh-pages)。

## 手順 2〜4: 埼玉県・千葉県・神奈川県

各県で次を行う。

- [ ] ABR の取得 (`eki-walk fetch abr-town-<code> abr-town-pos-<code>`。埼玉県は許可済み、千葉県・神奈川県はその県に進むときに確認を取る)。
- [ ] `configs/regions/<県>.toml` (bbox は N03 の範囲 + 3km から計算) と `configs/territory-<県>.toml`。
- [ ] `eki-walk build --config configs/territory-<県>.toml` (時間・メモリ・ekiwalk の格子との一致を記録)。
- [ ] `eki-walk combine --region tokyo --region <県> ...`。
- [ ] 確認: 乗換駅のまとまり、駅の読み、県境で縄張りがつながり色がそろうこと、主な駅の答え、データの大きさ。
- [ ] 文書 (`docs/data-sources.md`・`docs/validation.md`・README) を足し、公開の確認を取る。
