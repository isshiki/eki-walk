### 読み取り

- 多くの組で 50m 以内に合っている。こちらが短めに出る傾向がある。OSRM は駅の中心を 1 本の道に吸着して測るが、
  こちらは駅のまわりの複数の道 (半径内の節点) から測るため。
- 大きく外れたのは新宿駅の西 (都庁前・京王線新宿)。直線 215m・400m に対して OSRM が 545m・916m を返しており、
  巨大な駅の中心を離れた道に吸着したとみられる。こちらの値 (直線の 1.2〜1.3 倍) のほうが自然。
- 中野坂上 (大江戸線) は直線 236m に対して 240m。地点と駅が同じ山手通り沿いにあるため、ほぼ直線で歩ける。
- **起点の半径は 50m に決めた。** OSRM に近く、駅に近く見せすぎない (短めに出しすぎない) ほうが、物件探しの用途で安全なため。

`uv run eki-walk build --config configs/tokyo.toml` (Windows 11、Python 3.13)
