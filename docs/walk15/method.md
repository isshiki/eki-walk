# 計算方法と限界 (walk15)

> 旧版 (walk15、2026-10-03 公開、駅の縄張りマップに置き換え) の記録です。

設定値はすべて `configs/tokyo.toml` にあります。距離の計算は JGD2011 平面直角座標系 IX 系 (EPSG:6677) のメートルで行います。

## 1. 対象範囲

- N03 (2026 年) の東京都から、島しょ部 9 町村と所属未定地 (東京湾の埋立地) を `N03_007` のコードで除いた面。1,782.59 km²。
- 駅は、対象範囲から 1.5km 以内にホームがあるものをすべて入れる (都外の駅も含む)。対象範囲の端の地点から、都外の駅までの道のりを正しく出すためです。
- 道路網は、対象範囲を 3km 広げた矩形で取る。

## 2. 歩ける道

Overture の segment のうち `subtype = road` で、次のどれにも当たらないもの。

| 除外する道 | 判定 | 東京の抽出での本数の目安 |
|---|---|---|
| 高速道路・都市高速とそのランプ | `class = motorway` | 2,293 |
| 徒歩禁止 | `access_restrictions` に、条件なしで `foot` を含む (または交通手段の指定がない) `denied` がある。ただし `foot` の `allowed`/`designated` があれば歩ける | 約 7,000 (高速道路と重複あり) |
| 工事中・廃道 | `road_flags` で区間全体 (`between` なし) に `is_under_construction` か `is_abandoned` | 約 570 |

- 一方通行 (`heading`)・時間帯 (`during`)・利用目的 (`using`)・車両の大きさ (`vehicle`) などの条件がついた規制は、歩く人には当てはまらないとみなして無視する。
- 全面禁止 (`denied`、条件なし) の多くは、私有地の通路・駐車場内の道 (`class = service`) など。これを外すと、地点は隣の公道に吸着される。
- 結果: 1,107,926 本のうち 1,099,041 本が歩ける道。

## 3. グラフ

- 道は segment が持つ connector (ID と線上の位置 `at`) で区切り、connector を節点、区切った区間を辺とする。辺の長さは平面上の長さ (m)、向きはなし。
- いちばん大きくつながった部分だけを使う。切れた小さな断片に吸着して「0 駅」と出る誤りを防ぐため。

## 4. 駅

- N02 の駅 (路線ごとのホームの線)。同じ駅コードの線が複数の地物に分かれている場合は 1 本にまとめる。
- 鋼索鉄道 (鉄道区分コード `13`) は除く。
- 駅の中心は、ホームの線の中点 (線の長さの半分の位置)。線が離れた部分に分かれている場合は、その重心にいちばん近い線上の点。
- 「1 駅」の単位は N02 のグループコード (300m 以内で同じ名前の駅)。表示名はグループの代表駅 (駅コード = グループコード) の名前。

## 5. 道のり

- 起点: 駅の中心から半径 50m 以内の節点すべて (50m と 100m を比べて決めた。docs/validation.md)。それぞれ中心からの直線距離を最初の距離にする。半径内に節点がなければいちばん近い節点。ホームの片側の道にだけ付いて大回りになる誤りを減らすため。
- 駅ごとに、1,200m で打ち切った最短路を求める (`scipy.sparse.csgraph.dijkstra`)。
- 徒歩分数 = 道のり ÷ 80m、端数切り上げ、最小 1 分 (不動産の公正競争規約と同じ換算)。15 分以内 = 1,200m 以内。

## 6. 格子

- H3 解像度 11 (1 辺 約 25m、面積 約 2,150m²) のセルのうち、中心が対象範囲に入るもの。
- セルの道のり = セルの中心からいちばん近い歩ける道までの直線距離 + その点から辺の両端を通って駅までの道のりの小さいほう。
- いちばん近い歩ける道が 100m より遠いセルは「道から遠い」として答えを出さない。

## 7. 画面用の形

- 駅数の塗りと駅ごとの 15 分圏の輪郭は、セルをつないだ面を 10m で単純化し、座標を約 1m 単位に丸めたもの。
  形を軽くするための処理で、クリックの答え (セルの値) には影響しない。
- 輪郭は駅ごとの小さなファイルに分け、結果に出た駅の分だけ画面が読む。

## 8. 限界

- 距離はホームの中心から測っていて、駅の出口からではない。大きな駅や長いホームでは、出口によって数分違う。
- 信号待ち・坂・階段・踏切・地下の上り下りは入れていない。
- 道路データが欠けている所がある。私道や建物の中の通路の扱いは不確か。
- 物件広告の「徒歩○分」(駅の出入口から物件の敷地まで、80m = 1 分) とは起点が違う。
- 地点は約 25m の格子にまとめているので、格子の中での位置の違い (最大 約 25m) は区別しない。
